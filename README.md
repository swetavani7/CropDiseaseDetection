# Crop Disease Detection using Deep Learning

## Objective

Detect crop diseases from leaf images using CNN and Transfer Learning.

## Dataset

PlantVillage Dataset

## Technologies

- Python
- TensorFlow
- OpenCV
- NumPy
- Matplotlib

## Models

### Custom CNN
Accuracy: 87.2%

### MobileNetV2
Accuracy: 95.1%

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1 Score

## Results

Transfer Learning outperformed the custom CNN architecture by 7.9%.
